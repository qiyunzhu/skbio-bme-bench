# GTDB R232 bac120 test

- Method: BME in scikit-bio or NJ-R-D in DecentTree
- Replicate: Replicate run (0, 1, 2)
- Calculation: Runtime of the tree-building algorithm (sec)
- Full: Runtime of the entire analysis (sec)
- Memory: Memory consumption of the entire analysis (KB)
- RF: normalized Robinson-Foulds distance to reference tree
- Loss: BME loss (balanced tree length) against input distances
